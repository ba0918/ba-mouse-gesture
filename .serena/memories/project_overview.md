# プロジェクト概要

## プロジェクトの目的
BA Mouse Gestureは、Chrome拡張機能として動作するマウスジェスチャーツールです。セキュリティを重視し、シンプルで直感的な操作性を目指した企業レベル品質の拡張機能です。

## 主要機能
- **基本ジェスチャー**: 10種類（←→↑↓ + 複合ジェスチャー）
- **AI学習機能**: 適応的パターン認識、動的閾値調整
- **カスタムジェスチャー**: 独自パターンの作成・管理
- **軌跡表示**: リアルタイム可視化（色・太さカスタマイズ可能）
- **除外サイト機能**: URLパターンマッチング対応
- **完全オフライン動作**: 外部通信なし、セキュアな設計

## 技術的特徴
- **Clean Architecture**: 4層構成による責任分離
- **VanillaJS + TypeScript**: フレームワーク依存なし
- **Svelte**: UI層でのコンポーネント化
- **Chrome拡張機能 Manifest V3準拠**
- **TDD実践**: 368テスト・100%成功率
- **品質ゲート**: pre-commit/pre-pushフック
- **CI/CD完備**: GitHub Actions自動化
