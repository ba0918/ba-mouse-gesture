## 🚀 改善提案

### 1. 🎯 新機能提案（ユーザー要望対応）

#### A. スーパーリロード機能（要望対応）
**現状**: ↑↓で通常のページ更新のみ
**提案**: 新ジェスチャーでスーパーリロード追加

```
現在: ↑↓ = 通常リロード (chrome.tabs.reload())
提案: ↑↓↑ = スーパーリロード (キャッシュクリア + リロード)
または: Shift+↑↓ = スーパーリロード (修飾キー対応)
```

**実装方法**:
```javascript
// background-simple.js
case 'super_reload':
  await chrome.tabs.reload(tabId, {bypassCache: true})
  return 'Page super reloaded (cache cleared)'
```

#### B. 追加ジェスチャー候補
- **←→**: 前のタブに切り替え
- **→←**: 次のタブに切り替え
- **↑←**: ウィンドウを閉じる
- **↓↑**: ブックマーク追加
- **L字型（→↑）**: ページ内検索
- **円運動**: 設定画面を開く
